**角色名 `characters[].name`**：基础包通常使用韩文资源键（如 `시로코 부상`/`호시노`），见 [角色名清单](角色名清单.md)；overrides 使用实际 manifest 的 `Identifier`，可以是中文。

**表情 `faceId`**：两位编号字符串（`"00"`..`"17"`）。**每个角色的可用编号不同**（白子/茜香 7 个；星野 17 个）。常见 `01`=平静、`02`=惊讶、`03`=微笑、`04`=害羞、`05`=严肃、`06`=大喊或低落（**因角色而异**）；`00` 默认。逐角色表见 `人物表情对照表.md`。

**人物动作 `action`**：`1`=微微蹲一下(拿东西常用)；`2`=向左倒下；`3`=向右倒下；`4`=微微抖动；`5`=剧烈抖动；`6`=跳一下；`7`=跳两下。（倒下后若下一句不移除该角色，会自行站起。）

**外形 `shapeOverride`**：`1`=通话中(电话对面的电子形象)；`2`=阴影中(整个人黑色)；`4`=靠近(立绘放大)。

**出场/退场动画 `appear`**（= `AppearType` 枚举；字母指**滑动方向**：`L`=向左滑、`R`=向右滑。已由 `BepInEx/interop/Assembly-CSharp.dll` 反查枚举名 + 实测确认）：`0`=None（无/原地不动）；`1`=**AL**（从**右**滑入 ⇒ 观感“从右侧出现”）；`2`=**AR**（从**左**滑入 ⇒ 观感“从左侧出现”）；`3`=**A**（原地出现）；`4`=**DL**（向**左**滑出）；`5`=**DR**（向**右**滑出）；`6`=**D**（原地消失）。**默认规则：角色从与自己所在屏幕同一侧的那一边滑入**（站画面右→`1`，站画面左→`2`；中间用 `3`），仅剧情需要时才反向；退场同理（右→`5`，左→`4`，中间 `6`）。`AL/AR` 指滑动方向；`4/5/6` 是退场，不能当成入场。

## 语气气泡使用规则

气泡适合作为点睛之笔：让微妙反应更可见，增强角色个性、情绪与节奏。合时宜时鼓励使用，无须证明它不可替代。编号表说明符号含义，不能凭台词出现某个词就自动匹配；`0` 是生气，无气泡用 `-1`。

- **看上下文与角色**：选择当前角色确实表现出的反应，而不是给每句话贴情绪标签。可以突出潜台词、短暂停顿、小小的害羞或突然领悟，普通日常也可以有精彩的气泡；反应幅度应符合角色个性。
- **按演出节奏取舍**：不规定多少句一次、占比或间隔，也不限制同句人数。连串喜剧反应、递进情绪或多人同时吃惊时，连续/多人气泡都可合理使用；平稳交流则留出视觉留白。若连用只是反复说明同一种情绪，没有增加表现力，就减少或去掉。
- **贴合场景基调**：严肃、悲伤、紧张、含蓄场景也可使用合适的气泡，例如一瞬的泪滴或迟疑。判断符号是否增强当前情绪，避免夸张或嬉闹符号破坏氛围；场景没有转为喜剧时，不要为了热闹冲淡伤感或危险感。告白中的害羞、日常感谢中的爱心也可能合适，取决于关系与实际表达。
- **照顾反应对象与结束**：气泡可以给发言者，也可以给正在反应的旁观者；多人使用时分别有角色反应依据。该反应结束后明确恢复 `-1`。复制人物状态、切换节点或分支汇合时检查旧气泡，避免无意重复触发；刻意连续演出可以保留相应气泡，但不要把重复写同一编号误当作延长显示时间。

### 情境对照

以下是判断线索，不是台词类别的禁用清单。同一句话在不同上下文里，可以选择不同演出。

| 气泡 | 可以增强的表现 | 避免机械套用 |
|---|---|---|
| Question `6`、Think `13`、Bulb `14` | 好奇、迟疑、思索的节拍、想通关键点 | 有问号就加疑问，每句推理都加思考或灵光 |
| Exclaim `3`、Surprise `9` | 意外发现、被打断、预期落差、强调有力的反应 | 有感叹号就加惊叹，普通确认也反复吃惊 |
| Chat `1`、Respond `7`、Dot `2` | 闲聊氛围、俏皮回应、无语停顿 | 每句对话、每次答应、每个省略号都配气泡 |
| Heart `4`、Shy `8`、Music `5`、Twinkle `11` | 亲昵、害羞、哼歌、期待或开心的亮点 | 普通客套一律爱心；有 BGM 就当角色在哼歌 |
| Angry `0`、Upset `12`、Steam `17`、Sweat `10`、Sigh `16` | 生气、烦躁、气急、尴尬、松一口气的鲜明反应 | 语气稍强就发怒，有困难就反复冒汗 |
| Sad `15`、Tear `18`、Zzz `19` | 低落、落泪、困倦或睡着的可见表现 | 伤感台词逐句配泪滴，安静就当成睡着 |

例如“谢谢你”若只是礼貌交接，无气泡就自然；若角色收到珍贵心意、明显羞涩，Shy 或 Heart 可以点亮这一刻。“原来钥匙一直在我口袋里！”在寻找后的恍然大悟中可用 Bulb，接着同伴的无语可用 Dot；不必为满足间隔刻意拆散连续反应。

### 交付前复核

结合前后台词查看气泡是否贴合角色、是否增强表达、连用是否形成有效节奏，以及反应结束后是否清空。删减没有情境依据、由标点机械匹配、无意重复或破坏氛围的气泡，保留能起点睛作用的安排。沿各条可播放分支查看实际效果，尤其注意跨节点复制与分支汇合；不以数量多少单独判定滥用。`validate` 仅检查枚举与结构，不能判断气泡是否合时宜。

**其它**：`bgmId` `999`=静音。

**BGM**：共 242 首，`bgmId` = 曲号（即 `theme_NN` 的 NN）。曲名/作者/建议用途见 `BGM用途注释清单.md`。**换曲要克制**：不要频繁切歌——只在**场景/情绪真正转折处**换（大体“一场景一曲”），同一首至少撑若干句；换得太快会让人工复核（试听）很吃力（用户 2026-10-08 交代）。
**弹窗图**：`Event01_<角色名>`（角色 CG）+ `popup02..popup221`（通用图）。注释见 `弹窗图注释清单.md`。
**音效**：`sound` 填**字符串名**（不带路径/后缀，如 `"SE_DoorOpen_01"`）。完整清单见 `音效名清单.md`（697 个，含 `SE_DoorOpen_01`/`SE_Knock_Soft_01` 等）。
**额外指令**（写进 `text` 字段，可多行，前缀 `#`；用于界面做不到的事）：`#wait;毫秒`（无对话的脚本等待后再推进）；`#bgshake`（背景抖动一次）；`#fx;AronaTouch`（特殊效果，目前仅序章的指纹识别）；`#zmc;模式;X,Y;缩放;持续ms`（背景平移/缩放；模式 `instant`=瞬时 / `smooth`=平滑）；`#st;[X,Y];模式;字号;` 与 `#stm;[X,Y];模式;字号;`（屏幕文字，分别左对齐/居中；模式 `instant`/`smooth`/`serial`；**末尾分号不可省**）；`#clearST`（清除屏幕文字——它不会自动消失）；`#<栏位号>;fx;shot`（指定栏位角色中弹特效，如 `#3;fx;shot`）；`#hidemenu` / `#showmenu`（隐藏 / 恢复右上角菜单）。屏幕中心为原点、宽固定 2960 单位。
**对话文字富文本**：`[size=字号]文本[/size]`、`[RRGGBBAA]文本[-]`（颜色，如 `[FF0000]红[-]`）、`[ruby=注音]文本[/ruby]`；可嵌套（如 `[size=200][FF0000]x[/size][-]`）。
**栏位 = 屏幕位置**：`#1`=左、`#2`=中偏左、`#3`=中、`#4`=中偏右、`#5`=右；`#0`=发言者/旁白位。逻辑栏位与位置字段分开；移动的版本限制见 [工程格式](project-format.md)。
