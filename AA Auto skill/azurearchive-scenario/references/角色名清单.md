# AzureArchive 角色/NPC 名清单（韩文）

共 **1467** 个。`characters[槽].name` 填**这里的韩文原名**（如 `시로코 부상`）。
来源：资源包 `flatdata` → `CharacterHashDictionary`。

> AA 的角色名是**韩文**，且带变体后缀（`부상`=负伤、`테러`=恐怖、`수영복`=泳装 等）。
> 名字库含 NPC（店员、路人、群演）。**有立绘资源的约 535 个**（对应 `characters_assets_*all.bundle`），其余多为 NPC。
