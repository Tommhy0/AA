# AzureArchive 人物表情（微表情）对照表

来源：各角色资源包内的 Spine 骨架（`characters_assets_*all.bundle` → `*_spr.skel`）中的表情名。
**用法**：`.aap2` 里 `characters[槽].faceId` 填**两位编号**（如 `"03"`）；不填或 `"00"` 是默认。
表情名保留**游戏原始英文名**（含官方拼写错误），中文为释义。

- 有表情数据的角色 **401** 个；无表情数据（NPC/面具/`_nd` 等变体）**133** 个。
- 若某编号出现多次（如星野有 3 个 `difficult`），说明有**多张不同的画**，播放时确认。
