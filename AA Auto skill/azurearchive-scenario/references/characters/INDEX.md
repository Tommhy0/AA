## 资料边界

- 来源是社区整理的游戏文本，固定提交 `6c4091603ca76d7d8c3cdb9104933f52cd8cab8e`；上游标注数据获取日期 2026-04-22。这个日期不保证已覆盖当时或今天的全部游戏内容。
- 上游已注明阿拜多斯主线第三章有 8 话空缺，部分活动/社团名称仍是数字代号，指令、旁白与分支也可能不完整。
- 核对中发现部分 MomoTalk Answer 区、连续对话有可疑说话人归属，以及分支重复台词。不把它们直接用于归纳口癖或关系。检索工具默认排除 MomoTalk Answer 区；其他说话人仍须语义核对。
- 同名目录混放多个衣装的羁绊，按角色 ID 分开；衣装不是独立性格，重大成长阶段也不是衣装 ID 就能表达的。
- 日文来源整理为中文倾向描述，译名保留常用别名；中文版称谓应自然表达，不照搬日文语尾或敬称。
- 当前 72 张卡重点支持基础日常，主线重大转折、未覆盖关系和新角色启用按需检索。没有证据就保留未知，不凭模型记忆填空。

角色库保存摘要、短例与出处；完整剧情留在外部缓存，避免默认加载或随技能重复打包。
