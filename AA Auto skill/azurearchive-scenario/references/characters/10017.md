# 洁莉诺 / チェリノ

基础版本 ID：`10017`。别名：连河洁莉诺、Cherino。
覆盖：基础简介、大厅与一段基础羁绊的初版证据档案；补充定位一段社团/主线互动。未完成全剧情、全部关系或衣装分析。资料快照日期为 2026-04-22。

## 明确设定与场景事实

赤冬学生会长，任性、重视权力，反复经历失势与复位；把胡子视为权威象征是其自身认知。 [P][B]

## 写作倾向（根据所列材料归纳）

- 说话方式：命令感强，可称老师为同志；夸张威严与孩子气能随情境切换。 [L]
- 情境反应：午睡后担心老师忘记自己，会提出布丁等具体要求，以强势表达寻求关注。 [B]
- 人物关系：把老师纳入自己的权威与事务安排；与部下的互动不能仅凭头衔推断。 [P][L][B][R]
