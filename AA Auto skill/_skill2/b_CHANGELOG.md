# 更新日志（AzureArchive 剧情技能）

当前版本：**3.2**。自动编译版原标记 1.7，按用户要求修正为 **2.0**；功能内容不变，后续气泡指引版为 **2.1**。

## 3.2 — 2026-10-11（UTC+8）

- 剧情交付必须包含预览标题与入口标题；保留已有标题，缺失时根据剧情拟题，副标题按需填写。
- 新增 `validate/compile --require-title`，在编译前定位缺失标题；旧工程普通校验仍可使用。
- 生成器对缺省、null 或空白标题回退到工程名称；同步示例、校验测试与双端技能。

## 3.1 — 2026-10-11（UTC+8）

- 每个对话选项节点指定一个 Auto 选项，工程中以 `DefaultOptionId` 指向该节点选定的 `OptionId`，确保自动播放/录制有可继续的路线。
- 保留用户已选路线，新增或缺失时按剧情与汇合后衔接选择；不在选项文字中拼接 auto，不改选项 ID 与分支目标。
- 静态校验提示缺失 Auto；新增 `validate/compile --require-auto` 录制准备检查，缺失时阻止交付或编译。
- 示例工程设置 Auto，版本、文档、脚本和技能包同步更新。

## 3.0 — 2026-10-10（UTC+8）

本次人物证据库更新按用户指定编号为 3.0，取代临时编号 2.2。

- 默认使用剧情证据档案维持角色一致，复杂关系、重大转折、缺卡或证据矛盾时才按需查询原文。
- 增加72名常用学生的初版档案，区分设定/场景事实、语气与反应归纳、人物关系、OOC提醒和阶段边界；每卡保留固定提交及证据范围，共293处。
- 建立135个语料角色名、244个版本ID的资料索引，索引项与已分析性格卡分开标识，不把衣装当成独立性格。
- 增加离线读取、别名消歧、有界原文检索和出处校验工具；处理同名衣装、续行台词、分支重复与可疑MomoTalk回答区，源文件变化后不沿用旧链接。
- 完整剧情放在外部缓存，技能只打包摘要、短例、索引与出处，保留原先灵活的气泡指引和自动编译流程。

## 2.1 — 2026-10-10（UTC+8）

- 气泡作为点睛之笔，鼓励符合情境、角色与节奏的使用，避免标点匹配、逐句贴标签和无意重复。
- 根据用户反馈取消固定句数、比例、间隔和同句人数限制；连续反应、多人反应按实际演出价值取舍。

- 移除示例中两处缺乏明显演出依据的气泡，保留台词与全部工程标识；普通交接并非禁止使用，仍须结合上下文判断。
